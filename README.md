Repository dei materiali del manuale (immagini, artefatti digitali, icone), pubblicato come sito su GitHub Pages:

## Struttura

```
manuale/
├── img/                          → icone condivise, usate in tutti i capitoli
└── volume2/
    └── sezioni/
        └── 1/
            ├── img/               → immagini specifiche della sezione
            ├── artefatti/         → pagine HTML interattive della sezione
            └── README.md          → riepilogo con tutti i link della sezione
```
